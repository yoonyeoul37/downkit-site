DownKit for Windows

Versi 0.1.4 (97 MB) · OS yang didukung: Windows 10 / 11 (64-bit)

Unduh versi Windows
Cara instalasi

Panduan instalasi 4 langkah mudah

  1. 1

    Unduh file instalasi

    Klik tombol [Unduh versi Windows] di atas untuk mengunduh file instalasi.

  2. 2

    Jalankan file instalasi

    Buka file yang telah diunduh; jika muncul peringatan SmartScreen ('Windows melindungi PC Anda'), klik [Info selengkapnya] → [Tetap jalankan].

    Mengapa jendela ini muncul?Program baru dapat menampilkan pemberitahuan ini karena informasi reputasi dari Microsoft belum cukup. DownKit tidak menginstal iklan atau program lain. Setelah sertifikasi tanda tangan kode (code signing) selesai, pemberitahuan ini mungkin tidak lagi muncul.
  3. 3

    Lanjutkan instalasi

    Ikuti petunjuk wizard untuk menyelesaikan instalasi. Anda dapat memilih apakah akan membuat pintasan di desktop.

  4. 4

    Hubungkan akun dan mulai

    Setelah menjalankan program, masuk dengan akun media sosial (Google, Naver, dll.) untuk langsung menggunakan layanan.

InternetMemerlukan koneksi internet
Komponen yang diperlukanMicrosoft Edge WebView2 (sudah tersedia di Windows 11 dan umumnya sudah terinstal di Windows 10.)

Menghapus program

Anda dapat menemukan dan menghapus DownKit di menu [Aplikasi & fitur] pada Pengaturan Windows. (File yang sudah diunduh dan diedit tetap tersimpan.)

Pembaruan perangkat lunak

Saat versi baru dirilis, Anda akan menerima pemberitahuan, dan program diperbarui otomatis melalui [Perbarui sekarang].

Panduan penggunaan dasar

Di mana file yang diunduh disimpan?

Lokasi penyimpanan default adalah folder 'Unduhan'. Anda dapat mengubahnya di menu [Pengaturan] > [Unduhan], dan mengklik ikon folder di daftar untuk langsung membuka folder penyimpanan.

Saya hanya ingin mengambil file audio (MP3)

Setelah memasukkan tautan, pilih format [Ekstrak MP3]. Setelah format ditentukan, pengaturan tersebut akan diterapkan sebagai default berikutnya.

Program tidak merespons saat tautan disalin

Periksa apakah 'Deteksi otomatis tautan yang disalin' sudah diaktifkan di menu [Pengaturan] > [Otomatis]. Untuk platform yang tidak didukung, Anda dapat menempelkan URL secara langsung untuk mengunduh.

Cara mengatasi galat unduhan

Unduhan tidak berjalan

1) Periksa koneksi jaringan, lalu klik [Unduh ulang]. 2) Di [Pengaturan] > [Info program], klik [Periksa pembaruan] agar mesin unduhan tetap terbaru. 3) Jika masalah berlanjut, kirimkan tautan tersebut melalui Hubungi Kami.

Situs menampilkan pesan pemblokiran sementara

Jika mengunduh dalam jumlah besar dalam waktu singkat, pembatasan sementara dapat terjadi sesuai kebijakan platform. Tunggu sebentar lalu klik [Unduh ulang].

Video 4K terunduh dalam 1080p

Versi gratis mendukung resolusi hingga 1080p. Bahkan dengan versi Pro, jika sumber aslinya tidak mendukung 4K, video dapat tersimpan dalam kualitas yang lebih rendah.

Mengunduh video yang memerlukan verifikasi usia atau login

Di versi Pro, Anda dapat menghubungkan akun melalui menu [Pengaturan] > [Login situs] lalu mengunduh. Informasi autentikasi hanya disimpan dengan aman di PC Anda.

File subtitle tidak dibuat

Aktifkan opsi 'Unduh bersama subtitle' di menu [Pengaturan] > [Unduhan]. Namun, jika video asli tidak memiliki subtitle dalam bahasa tersebut, file subtitle tidak akan dibuat.

Pembatasan unduhan konten yang dilindungi DRM

Konten yang menggunakan DRM (manajemen hak digital), seperti dari layanan streaming, tidak dapat diunduh karena alasan teknis.

Galat pemutaran di pemutar bawaan

Tergantung spesifikasi PC dan lingkungan codec, video mungkin tidak tampil dengan lancar di jendela pemutar bawaan. Dalam hal ini, klik [Buka dengan program lain] untuk menontonnya di pemutar media default PC.

Akun dan paket

Waktu pengaturan ulang jatah unduhan gratis

Jatah 15 kali diisi ulang setiap Senin pukul 00.00 tengah malam. Sisa jatah dapat dilihat di menu atas dan di [Pengaturan] > [Akun].

Cara menggunakan saat mengganti PC · ponsel

Setiap akun dapat mendaftarkan dan menggunakan hingga 3 perangkat, gabungan PC dan ponsel. Hapus pendaftaran PC lama di [Pengaturan] > [Akun], lalu masuk di PC baru.

Pembatalan langganan dan pengembalian dana

Anda dapat membatalkan langganan kapan saja melalui menu [Pengaturan] > [Akun]. Setelah dibatalkan, manfaat Pro tetap berlaku selama sisa periode, dan jika masih dalam 7 hari sejak tanggal pembayaran, Anda dapat meminta pengembalian dana sesuai kebijakan.

Pertanyaan lainnya

Muncul peringatan SmartScreen (Windows melindungi PC Anda)

Ini adalah pemberitahuan normal yang dapat muncul karena program yang baru dirilis belum banyak dikenal. Anda dapat melanjutkan instalasi dengan aman melalui [Info selengkapnya] > [Tetap jalankan].

Cara mengirim file log galat (Log)

Klik [Buka folder] di bagian [Pengaturan] > [Info program] > [Log galat], lalu lampirkan file downkit.log di dalam folder tersebut ke email Hubungi Kami agar kami dapat menganalisisnya dengan cepat.
